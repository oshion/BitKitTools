# 원문 자료 — 나와 닮은 치이카와 친구는?

> 이 파일은 사용자가 2026-11-06에 전달한 기획서에서 구현에 필요한 **문구 원문**만 옮긴 것이다. 채점표·기준 답안·화면 구성 등 규칙은 `docs/screens/fun-chiikawa-personality-test.md`가 정본이며, 기획서 원안 채점표는 수정되었으므로 여기에 싣지 않는다.
> 옮기면서 바꾼 것: (1) Q23 질문 문구를 스펙대로 "친구들이 나를 한마디로 표현한다면?"으로 변경, (2) 캐릭터 데이터의 "MBTI" 항목명을 "팬 설정 성격 유형"으로 변경(노출 문구에 "MBTI" 금지 — 스펙). 그 외 문구는 원문 그대로다.

## 3. 캐릭터 16명 결과 데이터 (KO 원문, 순서 = 기준 답안 표 순서)

1. 치이카와

* 팬 설정 성격 유형: ISFJ
* 핵심 성향: 여린 마음, 최선을 다하는 태도, 섬세함
* 강점: 공감 능력, 성실함, 배려심
* 주의점: 걱정이 많고 자신감이 부족할 수 있음
* 인간관계: 신뢰와 편안함을 중요하게 생각함
* 잘 맞는 캐릭터: 하치와레, 시사
* 서로 배울 점이 있는 캐릭터: 우사기

2. 하치와레

* 팬 설정 성격 유형: ENFJ
* 핵심 성향: 긍정적이고 다정하며 사교적임
* 강점: 공감 능력, 친화력, 긍정적인 에너지
* 주의점: 다른 사람을 챙기느라 자신의 감정을 미룰 수 있음
* 인간관계: 주변 사람에게 힘과 용기를 주는 관계를 선호함
* 잘 맞는 캐릭터: 치이카와, 오데
* 서로 배울 점이 있는 캐릭터: 쿠리만쥬

3. 우사기

* 팬 설정 성격 유형: ESTP
* 핵심 성향: 즉흥적이고 독립적이며 행동력이 강함
* 강점: 순발력, 대담함, 위기 대처 능력
* 주의점: 타인의 감정을 놓칠 수 있음
* 인간관계: 서로 간섭하지 않고 자유롭게 지내는 관계를 선호함
* 잘 맞는 캐릭터: 모몽가, 장수풍뎅이
* 서로 배울 점이 있는 캐릭터: 치이카와

4. 모몽가

* 팬 설정 성격 유형: ESFP
* 핵심 성향: 자기표현을 즐기고 관심받는 것을 좋아함
* 강점: 표현력, 자신감, 즐거움을 찾는 능력
* 주의점: 자기중심적으로 보이거나 타인의 반응에 민감할 수 있음
* 인간관계: 관심과 애정을 적극적으로 표현하는 관계를 선호함
* 잘 맞는 캐릭터: 우사기, 파자마 파티즈
* 서로 배울 점이 있는 캐릭터: 노동 갑옷씨

5. 쿠리만쥬

* 팬 설정 성격 유형: ISTP
* 핵심 성향: 차분하고 독립적이며 자신만의 취향이 확실함
* 강점: 침착함, 실용성, 독립적인 문제 해결
* 주의점: 무심하거나 표현이 부족하게 보일 수 있음
* 인간관계: 적당한 거리와 편안함을 중요하게 생각함
* 잘 맞는 캐릭터: 노동 갑옷씨, 랏코
* 서로 배울 점이 있는 캐릭터: 하치와레

6. 시사

* 팬 설정 성격 유형: ISFJ
* 핵심 성향: 예의 바르고 성실하며 배우려는 마음이 큼
* 강점: 책임감, 꾸준함, 겸손함
* 주의점: 타인의 기대에 맞추느라 자신을 과소평가할 수 있음
* 인간관계: 존중과 신뢰를 바탕으로 한 관계를 선호함
* 잘 맞는 캐릭터: 치이카와, 하치와레
* 서로 배울 점이 있는 캐릭터: 우사기

7. 랏코

* 팬 설정 성격 유형: ESTJ
* 핵심 성향: 자신감 있고 목표와 기준이 분명함
* 강점: 추진력, 책임감, 자기관리
* 주의점: 자신과 타인에게 지나치게 엄격할 수 있음
* 인간관계: 서로의 역할과 책임을 존중하는 관계를 선호함
* 잘 맞는 캐릭터: 쿠리만쥬, 노동 갑옷씨
* 서로 배울 점이 있는 캐릭터: 치이카와

* 강점: 상상력, 공감 능력, 진정성

* 인간관계: 자신의 내면을 이해해 주는 깊은 관계를 선호함
* 잘 맞는 캐릭터: 데카츠요, 치이카와
* 서로 배울 점이 있는 캐릭터: 랏코

9. 아노코

* 팬 설정 성격 유형: ISFP

* 잘 맞는 캐릭터: 데카츠요, 쿠리만쥬

* 강점: 감수성, 개성, 솔직한 감정 표현

* 인간관계: 자신을 있는 그대로 받아주는 관계를 선호함
