# BitKitTools.com 주간 SEO/콘텐츠 리포트 (2026-09-19 ~ 2026-09-25)

## 1. 잘 되고 있는 것

이번 주 클릭은 총 2건 발생했으며, 둘 다 **KO(한국어) 페이지**에서 나왔습니다.

- `/ko/baby/sleep-schedule/`: 노출 2회, 클릭 1회 (CTR 50%)
- `/ko/travel/layover-connection-calculator/`: 노출 6회, 클릭 1회 (CTR 16.7%)

다만 표본이 각각 2회, 6회 노출로 매우 작아 통계적으로 유의미하다고 보기는 어렵습니다. Week-over-Week로는 클릭이 3건→2건(-33.3%)으로 오히려 감소했고, 세션은 지난 주에 이어 이번 주도 0을 유지했습니다. 전체적으로 **아직 뚜렷한 성과 반등으로 판단할 만한 데이터가 부족**하며, KO 페이지가 EN 페이지보다 상대적으로 클릭을 잘 받는 패턴(09월 1주차부터 반복 관찰)이 이번 주에도 이어졌다는 점 정도가 유의미한 신호입니다.

## 5. 검색 의도 분류 요약

상위 쿼리 30개 분류 결과 대부분이 **tool 의도(약 22~23개)**로 나타났습니다. 이는 사용자들이 이미 "계산기/변환기를 바로 쓰겠다"는 명확한 목적으로 유입되고 있음을 의미하며, 랜딩 페이지가 도구 UI 위주로 구성된 현재 방향성이 타당함을 뒷받침합니다.

- tutorial 의도: "hydrometer calibration", "맥주 비중 평가 방법" 2건 — 사용법/원리 설명 콘텐츠에 대한 소수 수요 존재
- ambiguous: "alcohol measurement", "flight connection times data", "yes", "other", "airport connection times data" — 5건. 이 중 "flight connection times data", "airport connection times data"는 여행 카테고리 데이터/통계성 검색으로 해석될 여지가 있어, 단순 계산기보다 통계 표 형태 콘텐츠 보강 여지가 있습니다.

전체적으로 tool 의도가 압도적이므로, 콘텐츠 전략은 **설명형 글쓰기보다 "입력 즉시 결과"에 집중하고, 타이틀에 결과물(계산값)을 직접 노출**하는 방향이 CTR 개선에 더 유리할 것으로 판단됩니다.

## 6. 순위 변동 쿼리

- **"alcohol measurement"** (`/beer/standard-drinks-calculator/`): 90위 → 84위로 **6계단 상승**. 09월 1주차 리포트에서도 85→76위로 개선 흐름이 관찰된 쿼리로, 두 시점을 종합하면 이 쿼리에 대한 순위 개선이 우연이 아닌 지속적 추세일 가능성이 있습니다. 다만 여전히 80위권 밖이라 실제 클릭 전환까지는 거리가 있습니다(이번 주 해당 페이지 CTR은 0%).

같은 쿼리가 rising/falling 양쪽에 모두 표기되어 있으나 positionChange가 +6(개선)로 동일하므로, 이는 상승 신호로 해석하는 것이 타당합니다.

## 8. 추가 아이디어 제안

리포트 검색 의도 분류 결과 중 **"og calculator extract"**, **"extract og calculator"** 쿼리가 tool 의도로 분류되었으나, 사이트 내 상위 페이지 목록·zeroCtrPages·과거 이력 어디에도 이에 대응하는 명확한 "OG(Open Graph) 태그 추출/생성기" 도구가 확인되지 않습니다. 이는 잠재적인 **키워드 갭**일 수 있습니다. 다음 단계로:
1. 사이트 내 실제 OG 관련 도구(og-extractor 등) 존재 여부 확인
2. 존재하지 않는다면 검색량/경쟁 강도를 먼저 조사한 뒤, developer 카테고리(json-formatter, jwt-decoder, json-to-sql과 인접한)에 신규 도구 제작 여부를 검토
3. 존재한다면 왜 이 쿼리로 노출조차 안 잡히는지(색인/타이틀 매칭 문제) 점검

이 제안은 과거 이력의 "성장 spec 근거 부족" 사례들과 달리, 실제 이번 주 검색 의도 분류 데이터에서 직접 관찰된 신규 패턴이므로 우선 존재 여부 확인부터 시작하는 것을 권장합니다.

샘플 5개 페이지 모두 Performance 95~100점, Best Practices·SEO 100점으로 전반적으로 매우 양호합니다. 다만 5개 페이지 전부 **Accessibility가 95~96점으로 일관되게 100점에 못 미치는 패턴**이 관찰됩니다. 볼륨 있는 이슈는 아니지만, 반복되는 패턴이라는 점에서 색상 대비(color contrast)나 폼 요소의 ARIA 라벨 누락 같은 공통 컴포넌트(헤더/푸터/입력 폼) 이슈일 가능성이 있습니다. 우선순위는 낮으나, 공통 컴포넌트 1곳만 수정해도 전 페이지에 반영될 수 있어 비용 대비 효율이 좋을 수 있습니다. Performance 점수 자체는 이미 지난 리포트에서 조사 보류로 결정된 바 있어 이번에는 별도 조사를 제안하지 않습니다.
