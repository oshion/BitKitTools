## 5. 검색 의도 분류 요약

- 상위 30개 쿼리 중 27개가 **tool 의도**, ambiguous 2개("alcohol measurement", "flight connection time"), tutorial 1개("hydrometer calibration").
- 압도적으로 tool 의도가 우세하다는 것은 사용자가 "바로 계산/변환 결과를 얻으려는" 목적으로 유입되고 있다는 뜻이며, 현재 사이트 구조(계산기형 단일 페이지)와 잘 맞음 — 즉 콘텐츠 포맷 자체는 의도에 부합.
- tutorial 의도 쿼리("hydrometer calibration")는 `hydrometer-temperature-correction`이 다루는 "온도 보정 계산"과는 결이 달라(교정 방법 vs 보정 계산) 완전히 일치하지 않음. 다만 해당 페이지는 이미 여러 차례 재작성 시도 후 효과 없음 판정을 받았으므로, 이 쿼리 하나만으로 추가 수정에 나서는 것은 신중해야 함.

## 8. 툴 품질 신호

- **toolEngagement**: `/` 세션 8, engagementRate 0 — 홈페이지는 입력 필드가 없는 랜딩 구조이므로 engagementRate 0은 자연스러운 수치이며 UX 문제 신호는 아님.
- **claritySignals**: DeadClickCount 8세션 (json-formatter, 홈, ko 홈, developer 아티클 2종), QuickbackClick 5세션(유사 페이지군), RageClickCount 1세션(ko developer 아티클). ScriptErrorCount는 이번 주 목록에 없음(발생 0건 — 실제 JS 버그는 확인되지 않음).
- json-formatter와 developer 아티클 페이지에 DeadClick·Quickback이 반복적으로 몰리는 패턴은, 클릭 유도처럼 보이지만 반응이 없는 UI 요소(예: 비활성 버튼, 장식용 배지, 코드블럭 복사 아이콘 등)가 있을 가능성을 시사. ko developer 아티클의 RageClick은 특정 요소(목차 링크 등)를 반복 클릭하는 패턴일 수 있음 — Clarity 세션 녹화 확인이 필요한 지점.
