## 5. 검색 의도 분류 요약

- **ambiguous 의도**: "hydrometer temperature", "alcohol measurement", "connection times", "genetic potential height" — 이 쿼리들은 사용자가 도구를 찾는지 정보를 찾는지 명확하지 않은 유형으로, 검색엔진이 혼합 결과(계산기 + 설명 아티클)를 노출할 가능성이 큽니다. 해당 쿼리와 연결된 페이지(hydrometer-temperature-correction, layover-connection-calculator, height-predictor)가 CTR 0 또는 저조한 것과 무관하지 않아 보입니다.
- **tutorial 의도**: "맥주 비중 평가 방법"(한국어), "how to decode jwt", "how do i estimate airport transportation time..." — 사용자가 "방법/설명"을 원하는데 페이지가 순수 계산기 형태라면 스니펫에서 매력도가 떨어질 수 있습니다. 흥미롭게도 "맥주 비중 평가 방법"과 매칭되는 `/ko/beer/hydrometer-temperature-correction/`이 이번 주 유일하게 클릭을 받은 페이지 중 하나입니다 — tutorial 의도 쿼리에 대응하는 설명형 콘텐츠가 일부 작동하고 있다는 신호일 수 있습니다.

**시사점**: ambiguous/tutorial 의도 쿼리군에 대해 "계산기이자 설명"이라는 점을 타이틀·스니펫에서 더 분명히 드러내는 것이 CTR 개선의 실마리가 될 수 있습니다(단, 과거 유사 타이틀 수정 시도가 일부 페이지에서 no-improvement 판정을 받은 바 있어, 전면 재적용보다는 §9 제안을 참고해 우선순위를 재검토할 필요가 있습니다).

# 성장 확장 Spec: `/travel/layover-connection-calculator/`

## 1. 현황 요약

- **연속 2주 클릭 상위 페이지**: 2026-09-26(1클릭), 2026-10-03(1클릭) — 최근 2주 연속으로 사이트 전체 클릭 상위 페이지 목록에 포함됨.
- **상대적 희소성이 핵심 근거**: 같은 기간 사이트 전체 주간 클릭 총량이 2~3건 수준(09월 4주차 리포트: 클릭 3→2건)인 점을 고려하면, 이 페이지의 주당 1클릭은 **전체 사이트 클릭의 약 1/3~1/2를 단독으로 차지**하는 비중이다. 이는 beer·baby·travel 카테고리 다수 페이지가 "노출 대비 클릭 0" 패턴을 지속하는 것과 뚜렷하게 대비된다(09월 4주차 리포트 명시).
- **EN/KO 패턴과의 연속성**: 09월 4주차 리포트는 "이번 주 클릭은 KO baby/sleep-schedule·KO travel/layover-connection에서만 발생, EN 버전은 여전히 CTR 0 지속"이라고 명시 — 이 페이지의 클릭도 KO 버전에서 발생했을 가능성이 높으며, 이는 hydrometer-temperature-correction에서 관찰된 "EN 노출75·클릭0 vs KO 노출4·클릭1(CTR25%)" 패턴과 구조적으로 유사하다.
- 단, 각 수치가 주당 1클릭 수준의 소표본이라는 점은 09월 1주차 jetlag-recovery-calculator 건에서 지적된 "노이즈 가능성"과 동일한 한계를 가지므로, 본 spec은 **검증 없이 큰 투자(신규 페이지 제작)를 제안하지 않고 저비용·가역적 조치 위주로 구성**한다.

## 2. 확장 방향 제안

### A. 내부링크 강화
- 같은 travel 카테고리 내 이미 존재하는 페이지에서 본 페이지로 맥락 링크 추가:
  - `jetlag-recovery-calculator` → "환승 시간을 먼저 계산해보세요" 형태로 layover-connection-calculator 링크 삽입 (여행 플로우상 자연스러운 연결: 환승 계산 → 시차 회복 계산)
  - `flight-delay-compensation` 계열 페이지 → "항공편 지연으로 환승 시간이 촉박하신가요?" 형태 링크 삽입
- 근거: 두 페이지 모두 동일 travel 카테고리이며 과거 리포트에서 이미 언급된 실존 페이지로, 신규 데이터 수집 없이 즉시 실행 가능한 저위험 조치.

### B. 콘텐츠/FAQ 보강
- 레이오버 계산기의 핵심 기능(환승 시간 계산)에서 자연스럽게 파생되는 검색 의도를 커버하는 FAQ 항목 추가 제안:
  - "국제선 환승 최소 연결 시간(MCT)은 얼마나 되나요?"
  - "환승 시간이 부족하면 수하물은 어떻게 되나요?"
  - "레이오버 중 공항 밖으로 나갈 수 있나요?"
- 근거: 별도의 쿼리 레벨 데이터는 리포트에 제공되지 않았으나, 이 항목들은 도구의 핵심 기능(환승 연결시간 계산)에서 직접 파생되는 의도이며, 과거 승인된 "Tanner 공식 FAQ 추가"와 동일한 방식(도구 본연의 기능 확장)이므로 반복 승인 가능한 패턴.

### C. hreflang/canonical 점검
- EN/KO 버전 간 hreflang 상호 참조가 정확히 설정되어 있는지 점검. 근거: 09월 4주차 리포트에서 확인된 "KO 버전이 클릭 발생, EN 버전 CTR 0 지속" 패턴이 이 페이지에도 적용될 가능성이 있으며, hydrometer-temperature-correction 사례에서 동일 구조가 관찰된 바 있음(단, 09월 3주차에 KO 단독 spec은 표본 부족으로 거절된 바 있으므로 **콘텐츠 재작성이 아닌 구조적 점검(hreflang 태그 존재 여부 확인)만 제안**).

### D. Schema.org 마크업 추가
- FAQPage 스키마(B항목과 연동) 및 가능하다면 SoftwareApplication/Calculator 스키마 추가.
- 근거: 이 페이지는 이미 노출 대비 클릭이 나오는 검증된 성과 페이지이므로, 리치 스니펫을 통한 SERP 노출 강화는 순위 개선 없이도 CTR을 추가로 끌어올릴 수 있는 저위험·고효과 조치. 이 페이지에 대해 과거 schema 조치 이력이 없음(반복 제안 아님).

### E. (보류) 서브 키워드 전용 페이지 분리
- 쿼리 레벨 데이터(어떤 검색어로 유입되는지)가 리포트에 제공되지 않아 **구체적 슬러그/타깃 키워드를 지금 특정할 근거가 없음**. flight-delay-compensation EU261/US 분리 제안이 쿼리 데이터 부재로 거절된 선례와 동일한 리스크이므로, 이번 spec에서는 신규 페이지 제작을 제안하지 않음. 대신 **GSC 쿼리 리포트 확보 후 재검토**를 후속 과제로 명시.

## 3. 우선순위 제안

1. **내부링크 강화 (A)** — 신규 콘텐츠 제작 없이 기존 페이지 수정만으로 즉시 실행 가능, 가역적이며 리스크 없음. 가장 먼저 실행.
2. **FAQ 보강 + FAQPage schema (B+D)** — 과거 유사 패턴(타이틀/FAQ 재작성)이 2주 내 순위 반응을 보인 선례(hydrometer-temperature-correction 93→84위)가 있어 검증 가능한 다음 단계로 적합. B와 D는 동시 작업 시 효율적.
3. **hreflang 점검 (C)** — 진단성 조치로 비용이 낮으나, 실제 영향은 B/D 적용 후 CTR 변화와 함께 관찰해야 인과관계 판단 가능하므로 3순위.
4. **서브 페이지 분리 (E)** — 데이터 확보 전까지 보류.

## 4. 기대 효과

- **클릭수**: 내부링크(A)로 인한 노출 증가 + FAQ/schema(B+D)로 인한 CTR 개선이 결합되면, 현재 주당 1클릭 수준에서 2클릭 이상으로 증가할 가능성 — 단, 사이트 전체 클릭 총량이 2~3건 수준인 소표본 환경이므로 2주 단위 관찰 필요.
- **노출(impression)**: A 조치로 내부 크롤링/링크 신호 강화 → 관련 travel 카테고리 페이지들과 함께 노출 기회 증가 예상.
- **CTR**: D(schema)로 인한 리치 스니펫 노출 시 순위 변동 없이도 CTR 상승 가능 — 과거 homebrew-recipe-calculator가 콘텐츠 업데이트만으로는 CTR 0%(no-improvement) 판정을 받은 사례가 있으므로, FAQ만으로는 부족할 수 있어 schema 병행이 중요.
- **세션(session)**: 사이트 전반에 걸쳐 수 주간 "세션 0 유지"가 지속된 구조적 이슈이므로, 본 spec만으로 세션 수 증가를 단정하지 않음 — 클릭 증가가 세션 전환으로 이어지는지는 별도 관찰 필요.
