## ⚠️ 알려진 리스크 (사용자 판단으로 수용)
- **캐릭터 권리**: 치이카와는 원작자·라이선스사가 상표권·저작권을 가진 IP다. 이미지를 빼고 이름만 쓰더라도 수익형(AdSense) 사이트에서의 사용은 상표·저작권 분쟁 및 AdSense 정책(권리 없는 저작물) 위반 판정 리스크가 남는다. 사용자가 이를 인지하고 진행을 결정했다. 권리자 요청이 오면 즉시 비공개 처리할 수 있도록 `tools-config.ts`의 `status`로 숨길 수 있는 구조를 유지한다.
- **이미지 사용 불가 근거**: 2026-11-06 사용자가 공식 종합 정보 사이트(https://chiikawa-info.jp/) 메인 페이지 전문을 확인 — 무료 배포 자료·이용규약·二次創作 가이드라인 없음, 하단 표기 `© SPIRALCUTE, INC. All rights reserved.` 따라서 캐릭터 이미지는 권리자 라이선스 없이 사용하지 않는다. 인터넷에 올라온 이미지(배경화면·블로그 등)도 사용 금지.
- **"MBTI" 상표**: Myers-Briggs Foundation 등록 상표. 위 결정대로 노출 문구에서 제외하고, 본문 고지에서만 "MBTI®와 무관한 비공식 테스트"로 언급한다.

## 결과 화면
원 기획서 6장 순서를 따르되, **이미지 자리에 이모지 + 대표색 카드**를 쓰고 두 성격 유형을 분리 표시한다.
1. 대표색 카드(큰 이모지) + "당신과 가장 닮은 치이카와 친구는?" + 캐릭터 이름 + 공식 사이트 링크
2. **나의 성격 유형**: 사용자 응답(Q1~Q16)으로 계산한 4글자 + 한 줄 설명
3. **{캐릭터}의 성격 유형(팬 설정)**: 캐릭터 데이터의 4글자 — "공식 설정이 아닌 제작자 추정"을 작게 표기
4. 한 줄 소개 → 성격 분석 → 나의 강점 → 주의하면 좋을 점 → 인간관계 스타일
5. 나와 잘 맞는 캐릭터 / 서로 배울 점이 있는 캐릭터
6. 닮은 캐릭터 TOP 3 (순위, 이름, 유사도 %)
7. 다시 테스트하기 / 결과 공유하기

## 진행 화면 요구사항
- 시작 화면(소개 문구 — 원 기획서 1장) → 시작 버튼
- 한 화면에 한 문항, 진행률 표시(n/24 + 바), 선택지 클릭 시 다음 문항으로 이동
- 이전 문항 버튼 — 기존 응답 유지, 다른 선택지를 고르면 덮어씀
- 다시 테스트하기 — 모든 응답 초기화
- 응답은 메모리 상태로만 보관(LocalStorage 미사용)

## 공유 (기존 baby temperament-quiz 패턴 재사용)
- 결과별 정적 라우트 `/fun/chiikawa-personality-test/result/[characterId]` 16개 + 같은 세그먼트 `opengraph-image.tsx`로 **대표색 배경 + 이모지 + 캐릭터 이름 텍스트만 있는 결과 카드 PNG** 생성(캐릭터 그림 없음). OG 이미지 생성 시 이모지 폰트가 없으면 이모지가 깨지므로, 이모지 렌더링을 구현 단계에서 확인
- 공유 버튼: `navigator.share` 우선, 미지원 시 `navigator.clipboard`로 링크 복사. 카카오톡에 링크를 보내면 OG 카드가 썸네일로 표시됨
- 공유 문구(원안): "나는 치이카와 친구 중 {캐릭터}와(과) 가장 닮았대! 내 성격 유형은 {XXXX}! 너는 어떤 캐릭터와 닮았을까?"
- 공유 URL에는 캐릭터 id만 담는다(개별 응답·성격 유형 미포함). 공유 페이지는 해당 캐릭터 프로필과 "나도 테스트하기" 버튼을 보여준다

## 디자인
- 사이트 다크 테마 위에서 **테스트 카드 내부만** 파스텔 포인트(핑크·민트·하늘색 계열, 보라/인디고 금지 — UI_GUIDE)와 둥근 버튼을 쓴다. 모바일 우선.
- 결과 캐릭터 카드(이모지·이름)가 결과 화면에서 가장 크게 보이도록 구성.

## 수용 기준 (원 기획서 10장 + 추가)
- [ ] 시작 화면 → 24문항(각 4지선다) → 결과, 진행률·이전 문항·응답 유지·다시 하기 동작
- [ ] 성격 유형은 Q1~Q16, 캐릭터는 Q17~Q24만 사용 (서로 독립)
- [ ] 위 수정 채점표·동점 규칙 그대로 구현 — 유닛 테스트: 축별 집계·동점, 캐릭터 유사도·TOP 3·동점 정렬
- [ ] 16명 데이터 누락 없음, 각 캐릭터의 기준 답안으로 응답하면 그 캐릭터가 1위 (유닛 테스트)
- [ ] 모든 캐릭터 쌍 기준 답안 차이 ≥ 3 (유닛 테스트 — 이후 데이터 수정 시 회귀 방지)
- [ ] 결과 화면에서 "나의 성격 유형"과 "캐릭터의 팬 설정 유형"이 구분되어 표시
- [ ] 결과 공유 페이지 16개 × EN/KO 정적 생성 + OG 카드, 공유 버튼 동작
- [ ] 캐릭터 이미지·로고 없음, 노출 문구에 "MBTI" 없음 (테스트로 검사)
- [ ] 16명 모두 이모지·대표색(서로 다른 색조, 보라/인디고 없음)·공식 사이트 링크(`officialUrl`) 보유 (유닛 테스트)
- [ ] 결과 화면·공유 페이지에 공식 사이트 링크 표시, 새 탭(`rel="noopener"`)으로 열림
- [ ] 팬메이드·비공식 안내 문구 표시 (EN/KO)
- [ ] 모바일 화면 최적화

## 구현 단계에서 사용자 확인이 필요한 것
1. 공식 사이트에 캐릭터별 상세 페이지가 있는지 확인 — 있으면 각 캐릭터 `officialUrl`을 그 주소로, 없으면 https://chiikawa-info.jp/ 유지
2. 아노코·데카츠요·오데 이모지 확정 (초안 🌸·💪·🤝)
3. 캐릭터 16명의 **영문 표기**(특히 갑옷씨 3명, 카니(후루혼야), 파자마 파티즈) — 공식 영문명 확인 후 확정
4. EN 문항·선택지·결과 문구 번역 검수
5. 16가지 성격 유형 한 줄 설명, 캐릭터별 한 줄 소개 초안 검수
