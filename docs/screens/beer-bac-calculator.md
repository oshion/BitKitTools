# Screen: BAC Calculator (Blood Alcohol Concentration)

## URL
`/beer/bac-calculator` (EN), `/ko/beer/bac-calculator` (KO)

## 공통 콘텐츠 구조
Title → Tool → Description → How To Use → Example → FAQ → Disclaimer(`medical`, + 전용 경고 배너) → Related Tools.

## ⚠️ 법적 리스크 — 반드시 숙지
음주운전 판단 근거로 오인될 수 있는 YMYL 툴이다. 표준 `medical` disclaimer만으로는 부족하며, 아래 강화 규칙은 **선택이 아니라 필수**다 (하네스 재세팅 논의에서 확정, profile v2 Section 13-5 / ADR-014).

## 목적
성별, 체중, 술 종류, 마신 양, 경과 시간을 입력하면 Widmark 공식 기반 예상 혈중 알코올 농도(BAC)를 계산해 보여준다. **운전 가능 여부 판단 용도가 아님을 최우선으로 전달한다.**

## 입력
- 성별 (남/여 — Widmark 계수 r값에 사용)
- 체중 (kg/lb 전환 가능)
- 음주 항목 추가 (술 종류 프리셋 선택 시 ABV 자동 채움 + 용량 mL)
- 음주 시작 후 경과 시간 (시간 단위)

## 출력/로직 (`lib/utils/bacCalculator.ts`)
- Widmark 공식: `BAC = (알코올 섭취량(g) / (체중(g) × r)) - (분해율 × 경과시간)`
- `calculateBac(input: BacInput): { bacPercent: number; hoursUntilZeroPercent: number; isEstimateOnly: true }` — 반환 타입에 `isEstimateOnly: true`를 고정해 컴포넌트가 이 필드를 무시하고 단정적 UI를 그릴 수 없게 설계
- **신규 출력: `hoursUntilZeroPercent`** — 현재 BAC가 분해율(고정 상수, 시간당 약 0.015%)로 0%에 도달하기까지 남은 시간. **경쟁사 조사에서 확인된 기능이지만 범위를 의도적으로 좁혔다: "법정 한도(0.08% 등 국가별 기준)까지 남은 시간"은 절대 추가하지 않는다** — 특정 임계값을 "그 시점부터 운전 가능"으로 오인시킬 위험이 너무 크다. **오직 0%(완전 대사)까지의 시간만 계산한다** — 0%는 국가/관할과 무관한 유일하게 모호하지 않은 기준점이라 안전하다.
- 결과 라벨은 반드시 "예상 0% 도달까지 남은 시간"처럼 중립적으로 표기하고, "그때 운전하세요/가능합니다" 류의 문구를 암시하지 않는다. 경고 배너(아래 UI 구성 1번)는 이 값 바로 옆에서도 동일하게 노출되어야 한다.

## UI 구성 (필수 안전장치)
1. **상시 노출 경고 배너** (닫기 버튼 없음, 페이지 최상단 고정 또는 결과 바로 위):
   > "이 결과는 운전 가능 여부를 판단하는 근거로 사용할 수 없습니다. 음주 후에는 절대 운전하지 마세요."
2. 결과는 **숫자(%)만 중립적으로 표시** — 배경색/아이콘으로 "안전"·"위험"·"운전 가능" 등급을 암시하지 않는다. 초록색·체크 아이콘·신호등 UI 전면 금지.
3. 임계값(예: 0.03%, 0.08% 등 국가별 법정 기준)과 무관하게 경고 배너 문구는 항상 동일하게 노출한다 — 수치가 낮다고 경고를 약화하지 않는다.
4. 표준 `<DisclaimerBanner disclaimerType="medical" />` 문구: "본 계산 결과는 의학적 조언이 아니며 참고용입니다. 실제 건강/음주 관련 판단은 반드시 전문가와 상담하시기 바랍니다." + 계산식 출처(Widmark formula, 학술 근거) 명시
5. 위 1~4는 `tools-config.ts`의 `disclaimerType` 값과 무관하게 이 컴포넌트에 고정 렌더링한다 (config로 끌 수 없음).

### 디자인 방향 — 크고 깔끔하게
- BAC(%) 값을 결과 카드에서 **가장 크고 단일한 시각적 초점**으로 만든다(`UI_GUIDE.md` 기본값 `text-3xl font-bold text-[#f59e0b]`보다 한 단계 키운 `text-5xl` 급 — 다른 요소와 경쟁하지 않게 이 숫자 하나만 크게).
- `hoursUntilZeroPercent`는 BAC(%) 값보다는 작게(보조 정보), 같은 카드 안에 나란히 두되 시각적 위계를 명확히 분리한다(예: BAC는 큰 숫자, 남은 시간은 그 아래 작은 라벨).
- 경고 배너는 색(빨강 계열)과 두께로 눈에 띄되, 카드 자체는 불필요한 장식(그라데이션, 그림자 글로우) 없이 단순하게 유지한다 — `UI_GUIDE.md` "AI 슬롭 안티패턴" 준수.
- 음주 항목 입력 리스트는 항목이 늘어나도 카드가 산만해지지 않도록 각 항목을 한 줄로 압축하고, 여백(`space-y-4` 이상)을 넉넉히 준다.

### BAC 구간별 참고 정보 (신규, 순수 교육 콘텐츠)
결과 카드 아래, FAQ 위쯤에 BAC 구간별 일반적인 신체 영향을 설명하는 참고표를 추가한다(calculator.net류 경쟁사 패턴). **표 안 어디에도 "이 구간이면 운전 가능"류의 문구를 넣지 않는다** — 순수하게 "이 정도 농도에서 일반적으로 나타나는 신체 반응"만 서술한다(예: 0.02~0.03% 미세한 온기·기분 변화, 0.08%+ 판단력·운동조절 저하, 0.30%+ 이상 의식 저하 위험 등 — 표 안 정확한 구간 값과 서술은 harness 구현 단계에서 신뢰 가능한 의학 자료 기반으로 작성). 표는 계산된 현재 BAC 값의 구간을 강조 표시하되, 색상으로 "안전/위험"을 암시하지 않고 단순 하이라이트(굵게/테두리)만 사용한다.

### Widmark 공식 명시 (신규)
Description 섹션에 실제 Widmark 공식을 수식으로 보여준다(경쟁사 DrinkFox 패턴 — E-E-A-T 신뢰 신호). 이미 disclaimer에 "공식 출처 명시"가 있었지만, 지금까지는 텍스트로만 언급했고 실제 수식은 노출하지 않았다 — 이번에 본문에 수식 자체를 추가한다.

## tools-config 항목
- `category: 'beer'`, `disclaimerType: 'medical'`, `aiOverviewResistance: 'high'`
- `relatedToolIds`에 신규 툴 `standard-drinks-calculator` 추가(상호 연결) — "혈중알코올농도가 아니라 순수 알코올량/표준잔이 궁금하다면" 용도로 구분 안내
- FAQ 예: "BAC 계산기로 운전해도 되는지 알 수 있나요? (아니오, 알 수 없습니다 — 이유 설명)", "Widmark 공식이란?", **"0%까지 남은 시간이 지나면 운전해도 되나요?"(신규, 반드시 포함) → "아니오"로 시작, 이 값은 대사 속도 추정치일 뿐이며 개인차·오차가 크고 실제 판단력 회복과 직결되지 않는다는 점을 명확히 설명**

## 상태
- 로컬 `useState`만. 입력값(성별/체중/음주량)은 민감할 수 있어 LocalStorage에 저장하지 않는다.

## Analytics 이벤트
`Tool Open`, `Calculate` — 개인 식별 가능한 입력값은 이벤트 payload에 포함하지 않는다.

## 금지사항
- "운전 가능", "안전", "OK" 등 통과/합격을 암시하는 어떤 표현·색상·아이콘도 사용하지 않는다.
- 경고 배너를 닫거나 숨기는 UI를 제공하지 않는다.
- 계산 결과값에 따라 경고 문구의 강도를 조절하지 않는다 (항상 동일 문구).
- **"법정 한도까지 남은 시간" 같은 국가별 임계값 기반 카운트다운을 추가하지 않는다** — 오직 0%까지의 시간만 계산한다(위 "출력/로직" 섹션 참고).
- BAC 구간별 참고표에 "이 구간이면 안전/운전 가능" 같은 판단성 문구를 넣지 않는다 — 순수 신체 반응 서술로만 구성한다.
