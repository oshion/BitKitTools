## 심각도 기준

| 심각도 | 기준 |
|--------|------|
| 높음 | 버그 유발 가능, 보안 문제, 타입 안전성 훼손 |
| 중 | 코드 냄새, 중복, 레이어 규칙 임시 우회 |
| 낮음 | 리팩터링 필요하지만 동작에 영향 없음 |

## 관리 원칙

1. 부채 발생 즉시 기록한다. 나중에 기억에 의존하지 않는다.
2. 해결되면 "해결된 부채" 섹션으로 이동한다. 삭제하지 않는다.
3. "높음" 부채가 3개 이상이면 다음 phase 시작 전에 해소한다.
